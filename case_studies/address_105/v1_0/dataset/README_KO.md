## 계산 대상

주소 105를 첫 15개 소수 풀로 작은 우선과 큰 우선 두 순서에서 조립한다. 각 순회는 소수마다 한 번 방문하고, 그 소수가 잔여값 이하이면 한 개를 채택한다. 전체 순회를 반복하여 잔여값이 0 또는 1이면 종료한다. 풀에서 소수를 제거하지 않으므로 다음 순회에 같은 표지를 다시 사용할 수 있다. 반복 부품은 발생 순번으로 구분한다.

검증 입력은 기존 공개 코드와 그 코드에 기록된 입자 정지에너지다. 주소, 풀, 조립 순서, 표지 5·47의 중성자 배정, 비활성 원천과 공통 예산은 모형의 구성 선택이다. 변환은 주소 조립 → 표지 보존 핵자 판독 → 미사용 원천·비정지에너지 포함 총예산이다. 산출은 11개 대 4개 부품, n 1개 + D 10개 대 n 1개 + D 3개이며 공통 총 바리온수는 11이다. 주소·Q/B/L·에너지 보존 또는 고정 규칙 재현이 실패하면 이 사례의 계산·연결이 실패한다.

이는 선언한 모형의 결정론적 계산 데이터다. 실험 측정 표본, 관측 입자 수 또는 우주 구성비의 표본으로 사용하지 않는다. D는 p+e+전자 반중성미자와 그 전체 에너지 차액을 포함하는 완성 묶음이다. 개별 스펙트럼, 준비 동역학, 핵반응 시간 진화, 광자 수송은 이 데이터셋에서 실행하지 않는다.

## 재현

Python 3.9 이상에서 추가 패키지 없이 실행한다. 에너지는 입력 소수 문자열을 Decimal 정밀도 40으로 계산한다. 자릿수는 배포 입력의 정밀도를 나타내며 측정 불확도를 새로 추정한 것이 아니다.

```sh
python reproduce.py --check
```

`reproduced/`에 결과를 만들고 `data/`의 5개 배포 결과와 바이트를 비교한다. 기본 출력 폴더는 별도 폴더이므로 배포 원자료를 덮어쓰지 않는다. 다른 출력 폴더는 `--output`으로 지정한다.

```sh
python reproduce.py --output my_recalculation --check
```

검사 28개는 주소, 단계별 잔여값, 부품·입자·원천 보존과 알려진 누락·중복 실패 대조다. 기존 코드 대조 13개는 원 조립 루프를 주소 배열 [105]와 가중치 [1]로 직접 실행해 K15의 결과와 비교하고 K15/K16 네 조립의 원천 최대값이 11임을 확인한 기록이다. 원래의 전체 N=1,000,000 계산이나 후속 반응 계산을 이 사례에서 다시 실행했다는 의미는 아니다. 검사 수는 독립 관측 검증 횟수가 아니다.

## 장부 해석

주소 합은 105이며, 두 경우의 주소 잔여값은 0이다. 큰 우선의 미사용 **원천** 바리온수는 7이다. 두 종류의 잔여를 혼합하지 않는다. 주소 정수는 MeV, 바리온수 또는 공간 좌표가 아니다.

공통 원천 에너지는 11 × 939.56542194 = 10335.21964134 MeV이다. D 한 개의 정지에너지는 938.27208943 + 0.51099895069 = 938.78308838069 MeV이다. 차액 0.78233355931 MeV는 반중성미자 관련 에너지·운동·반동 총예산에 한 번만 기록한다. 이 예산을 그대로 광자 에너지로 읽지 않는다. 비활성 원천은 선언한 모형의 준비 조건이며 실제 자유 중성자의 안정화를 주장하지 않는다.
